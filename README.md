## 📖 Loyiha haqida

Ushbu repozitoriy mening shaxsiy portfolio veb-saytimning manba kodlarini o‘z ichiga oladi. Loyiha **HTML5** va **CSS3** texnologiyalari asosida noldan yaratilgan bo‘lib, **GitHub Pages** xizmati orqali internetga muvaffaqiyatli joylashtirilgan. 

Saytning asosiy maqsadi — dasturlash yo‘nalishidagi bilimlarim, bajargan amaliy ishlarim hamda texnik ko‘nikmalarimni bir joyda tartibli va tushunarli ko‘rinishda taqdim etishdir.

## 📑 Sayt bo‘limlari

1. **Bosh sahifa (Hero Section)** — Qisqacha tanishtiruv va asosiy ma'lumotlar.
2. **Men haqimda (About)** — Dasturlashga bo‘lgan qiziqish va maqsadlar.
3. **Ko‘nikmalar (Skills)** — O‘zlashtirilgan texnologiyalar va vositalar ro‘yxati.
4. **Loyihalar (Projects)** — Amaliy mashg‘ulotlar davomida yaratilgan ishlar.
5. **Bog‘lanish (Contact)** — Ijtimoiy tarmoqlar va aloqa ma'lumotlari.

## 💻 Lokal kompyuterda ishga tushirish

Loyihani o‘z kompyuteringizda ko‘rish va tahrirlash uchun quyidagi amallarni bajaring:

1. **Repozitoriyni klon qiling:**
   ```bash
   git clone https://github.com.git
   ```
2. **Loyiha papkasiga kiring:**
   ```bash
   cd gh-pages-nodir
   ```
3. **Ishga tushiring:**
   `index.html` faylini ikki marta bosish orqali istalgan veb-brauzerda (Chrome, Edge, Firefox) oching yoki VS Code dasturidagi **Live Server** kengaytmasidan foydalaning.
